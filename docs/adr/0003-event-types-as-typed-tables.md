# 0003. Всё, что зависит от типа события, описывается таблицами `Record<EventType, …>`

Дата: 2026-10-11 · Статус: принято

## Контекст

Типов событий 13, и от типа зависит много: заголовок в ленте, поля на странице события, поля формы, обязательность,
привязка к семье, статус семьи. Это были большие `switch` (`getEventSummary` — когнитивная сложность 83,
`getEventFields` — 47) и цепочки `if (type === …)` в форме. Добавление типа требовало найти все места по памяти.

## Решение

Каждая зависимость от типа — таблица, ключи которой типизированы `EventType`:

| Что                        | Где                                             |
| -------------------------- | ----------------------------------------------- |
| заголовок и иконка в ленте | `DESCRIBE` в `utils/eventSummary.ts`            |
| поля на странице события   | `DESCRIBE` в `utils/eventDetails.ts`            |
| поля payload ↔ форма       | `PAYLOAD_FIELDS` в `utils/eventPayload.ts`      |
| обязательные поля формы    | `FORM_RULES` в `utils/eventPayload.ts`          |
| события без семьи          | `APIARY_SCOPED_TYPES` в `utils/eventPayload.ts` |
| заголовок формы            | `EVENT_FORM_TITLE` в `utils/eventLabels.ts`     |
| статус семьи после события | `STATUS_BY_EVENT_TYPE` в `utils/colonyState.ts` |

Безопасное чтение payload — `payloadNum`, `payloadText`, `labelOf` (`utils/payload.ts`): данные могут прийти
от более старой или новой версии сервера.

Неизвестный тип (сервер новее клиента) не ломает интерфейс: лента показывает сам тип, страница события — пустой
список полей.

## Последствия

- Пропущенная запись в `DESCRIBE` — ошибка компиляции, а не «пустая строка в ленте».
- Описание типа теперь набор небольших функций; их легко тестировать (`test/eventDescriptions.test.ts`
  фиксирует поведение для всех типов).
- Добавление типа всё ещё требует правок в нескольких файлах — полный список в
  [frontend-architecture.md](../frontend-architecture.md#события).

Отвергнуто: единый реестр «тип → все свойства». Красивее, но это новая абстракция сразу поверх шести файлов;
вернёмся к ней, если типы события начнут добавляться часто.
